# Goal

Version 1 of Seneschal provides explainable authorization for capability requests.

The goal is to prove the core governance model:

Identity submits a Request for a Capability, Policies are evaluated, a Decision is produced, and Audit Events are recorded.

---

# Must Have

- Identity Registry
- Capability Catalog
- Policy Management
- Request Submission
- Decision Generation
- Audit Event Recording
- Dashboard
- REST API

---

# Nice To Have

- Sample identities
- Sample capabilities

# Out of Scope

- Automatic capability discovery
- SaaS deployment

- Marketplace

- Approval workflows
- External identity federation

---

# Success Criteria

Version 1 is successful when a user can:

- Create an Identity
- Create a Capability
- Create a Policy
- Submit a Request
- Receive an explainable Decision
- View the Audit timeline
- Understand why a Request was allowed, denied, logged, or marked for approval
